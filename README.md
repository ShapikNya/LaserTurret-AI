# LaserTurret-AI

Модуль обработки видеопотока и вычисления углов наведения (yaw/pitch) в реальном времени.

Проект демонстрирует интеграцию компьютерного зрения, геометрических расчётов и управления внешним оборудованием.

---

## Функциональность

- Детекция объектов в реальном времени (YOLO / ONNX Runtime)
- Восстановление 3D-вектора цели из 2D-координат кадра
- Расчёт углов сервоприводов (yaw/pitch)
- Передача управляющих команд на микроконтроллер (Serial/USB)
- Визуализация детекции и диагностической информации

---

## Архитектура

Проект разделён на два режима:

**dev (консольный)**  
Высокопроизводительный режим для real-time обработки.

## Планируемое развитие

- разработка и обучение собственной нейросети, оптимизированной под насекомых и мелкие объекты;  
- внедрение трекинга и прогнозирования траектории движения цели;  
- расширение аппаратной части, улучшение точности и отзывчивости привода;  
- перенос части вычислений на микроконтроллер (в т.ч. лёгкие модели нейросети);  
- реализация кругового 360° обзора;  
- алгоритмы подавления шумов, ложных срабатываний и условий низкой освещённости;  
- создание полнофункционального стенда для полевых испытаний.
