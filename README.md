# LaserTurret-AI

Модуль системы лазерной турели, который обрабатывает изображения с камеры и выполняет распознавание целей с помощью нейросетевых моделей YOLO.  

## 📌 Текущий статус проекта

На данный момент реализованы две основные ветки разработки:

- **dev**  
  Консольный проект:  
  - работа с `YoloDotNet` в реальном времени,  
  - вывод FPS и информации о детектируемых объектах,  
  - управление запуском/остановкой детектора через клавиши (`W`/`S`/`Esc`).
    <img width="708" height="432" alt="image" src="https://github.com/user-attachments/assets/ceacb2af-1932-4ac0-be08-1c3a3a7bbdca" />

- **sandbox**  
  Windows Forms приложение:  
  - вывод изображения с камеры или файла на экран,  
  - выбор алгоритма распознавания:  
    - каскады Хаара (детекция лиц),  
    - нейросетевой детектор объектов (YOLO, ONNX).

## 🛠️ Технологии

- **C# (.NET)**
- **WinForms / Console**
- **Emgu.CV** (OpenCV для работы с изображениями и камерой)  
- **SkiaSharp** (отрисовка и обработка изображений)  
- **YoloDotNet** (детекция объектов через ONNX Runtime)  
- **ONNX** (модель YOLO: `yolo11n_fixed.onnx`)  
- **CUDA** (ускорение инференса на GPU NVIDIA)  

## 🚀 Планируемое развитие

- Расчёт углов поворота сервоприводов в зависимости от позиции цели.  
- Передача управляющих данных на COM-порт / USB-порт для связи с микроконтроллером.  
- Интеграция трекинга целей.  
- Оптимизация кода (ускорение работы с видео и изображениями, снижение нагрузки на CPU/GPU).
