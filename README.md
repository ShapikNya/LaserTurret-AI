# LaserTurret-AI

<img width="2048" height="1536" alt="image" src="https://github.com/user-attachments/assets/333e38d0-a937-41fb-9c58-5cd25968d6be" />

Программный модуль системы лазерного наведения, выполняющий обработку видеопотока, распознавание целей и вычисление параметров наведения (yaw/pitch) в реальном времени. Модуль является центральной частью контура управления: он получает изображение с камеры, определяет положение объекта в кадре, восстанавливает его пространственный вектор и передаёт управляющие команды микроконтроллеру для позиционирования лазера.


## 📌 Текущий статус проекта

На данный момент реализован функциональный прототип, включающий:

### ▣ Демонстратор технологии
- детекция объектов с камеры в реальном времени (YOLO / ONNX Runtime);
- восстановление **пространственного 3D-вектора цели по 2D-координатам** с учётом параметров камеры;
- вычисление углов поворота сервоприводов (yaw/pitch) для лазерного наведения;
- генерация управляющих команд и передача их на микроконтроллер.

### ▣ Ветки разработки

**dev** — консольный модуль:  
- интеграция `YoloDotNet` в режиме реального времени;  
- вывод FPS и информации по каждому детекту;  
- управление детектором через клавиши (`W`/`S`/`Esc`).

**sandbox** — WinForms-инструмент для визуальных экспериментов:  
- вывод видеопотока с камеры или файла;  
- выбор алгоритма детекции:  
  - каскады Хаара (детекция лиц),  
  - YOLO (ONNX-модели);  
- визуализация боксов, трекинга, координат.

## 🛠️ Используемые технологии

- **C# (.NET 8)**
- **WinForms / Console**
- **EmguCV (OpenCV)** — захват и обработка видеопотока
- **SkiaSharp** — отрисовка и графическая обработка  
- **YoloDotNet + ONNX Runtime** — нейросетевой инференс  
- **TensorRT** — высокопроизводительный инференс нейросетей на GPU
- **Serial COM / USB** — обмен с микроконтроллером  
- **Алгоритмы кинематики** — пересчёт 2D → 3D → сервоприводы  

## ⚙️ Реализованный функционал

- распознавание объектов (YOLO 11n);  
- калибровка камеры и расчёт направляющего луча;  
- восстановление **3D-вектора цели** из пиксельных координат;  
- вычисление углов наведения (yaw/pitch);  
- обмен с микроконтроллером и управление сервоприводами;  
- визуализация детекции и диагностической информации;  
- гибкий режим отладки (sandbox) и высокопроизводительный режим (dev).


## 🚀 Планируемое развитие

- разработка и обучение **собственной нейросети**, оптимизированной под насекомых и мелкие объекты;  
- внедрение трекинга и прогнозирования траектории движения цели;  
- расширение аппаратной части, улучшение точности и отзывчивости привода;  
- перенос части вычислений на микроконтроллер (в т.ч. лёгкие модели нейросети);  
- реализация **кругового 360° обзора**;  
- алгоритмы подавления шумов, ложных срабатываний и условий низкой освещённости;  
- создание полнофункционального стенда для полевых испытаний.
